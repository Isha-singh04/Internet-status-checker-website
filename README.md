 I created a responsive mini food website that checks your internet connection in real time. 👇

 ✅ When offline, a custom "You are Offline" page appears instantly with an enhanced background and smooth UX.
 ✅ I also added dynamic features like "Add to Orders", "View My Orders" panel, and "Remove Orders" — just like a real food delivery application!
